# TEP Aula 11 Publicador — site público

Site estático em português brasileiro com as informações públicas do aplicativo acadêmico **TEP Aula 11 Publicador**.

## Páginas

- `index.html` — apresentação do projeto
- `privacidade.html` — Política de Privacidade
- `termos.html` — Termos de Uso
- `exclusao-de-dados.html` — política e instruções para exclusão de dados
- `styles.css` — estilos compartilhados e responsivos

## Visualização local

Os arquivos não dependem de instalação ou compilação. Para conferir o site localmente, execute um servidor HTTP simples neste diretório e abra o endereço exibido pelo servidor.

## Publicação

O arquivo `.nojekyll` deixa o conteúdo pronto para ser servido diretamente pelo GitHub Pages a partir da raiz da branch de publicação.
